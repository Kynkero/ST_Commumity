# ST Community

Одностраничный сайт студии ST Community. Реализован на чистых HTML, CSS и JavaScript без внешних библиотек и внешних подключений.

## Структура проекта

- `index.html` — разметка страницы.
- `styles.css` — стилизация и дизайн интерфейса.
- `script.js` — небольшая интерактивность (диалог подтверждения и прокрутка наверх).

## Запуск

Откройте файл `index.html` в браузере.
